# مِرْباح — منصة تسعير للمشاريع الصغيرة

> **🔗 المعاينة المباشرة (الحاسبة التفاعلية):** https://adb707a.github.io/mirbah/
>
> ⚠️ **ملاحظة مهمة:** الرابط أعلاه يعرض **الواجهة الثابتة (الحاسبة/الدفتر)** فقط. المنصة الكاملة (الخادم Node.js + قاعدة SQLite + تسجيل الدخول + لوحة التاجر + لوحة المالك) تعمل **محليًا** عبر `npm start` أو على أي استضافة Node.js — ولا يمكن تشغيلها على GitHub Pages لأنه يقدّم ملفات ثابتة فقط.

مِرْباح يساعد صاحب المشروع الصغير على حساب تكلفة منتجاته وتنظيم مكوّناته ومصاريفه، وتحديد سعر بيع مناسب بهامش ربح واضح — من أول مكوّن إلى سعر البيع.

## ✨ أبرز المميزات

- **دفتر تسعير (حاسبة)**: احسب تكلفة المنتج من المكوّنات والتغليف والتشغيل، وحدد سعر البيع والربح ونقطة التعادل.
- **مكتبة مكوّنات ذكية**: 20 نشاطًا · 51 تصنيفًا · 68 منتجًا · 463 اقتراح مكوّن (مقترحات ذكية حسب نوع المنتج).
- **حسابات ولوحات**: تسجيل دخول للتجار، لوحة تاجر (مشاريع/منتجات/وصفات)، ولوحة مالك مستقلة (إدارة التجار والكتالوج والمحتوى).
- **أمان مفصول حقيقيًا**: أدوار (زائر/تاجر/مالك)، جلسات httpOnly، CSRF و Origin protection، قفل محاولات الدخول، TOTP للمالك، وعزل بيانات التجار.
- **بلا تبعيات خارجية**: Node.js فقط (`node:sqlite`)، لا حزم npm خارجية.

## 🛠️ التقنية

- **الخادم**: Node.js (≥22) · `node:sqlite` (قاعدة SQLite مدمجة) · جلسات كوكي.
- **الواجهة**: HTML/CSS/JS عادي (Tailwind عبر CDN) · Chart.js.
- **الاختبارات**: `node:test` — **51 اختبار منصة + 31 حساب + 11 اقتراح** (كلها خضراء).

## 🚀 التشغيل المحلي

```bash
npm start
```

ثم افتح `http://localhost:8788/` (الحاسبة)، و`/login` (دخول التاجر)، و`/owner-admin` (لوحة المالك).

حسابات تجريبية (محلية فقط): تاجر `demo@mirbah.local` / `Demo-Trader-2026` · مالك `owner@mirbah.local` / `Mirbah-Owner-2026!`.

## ⚠️ ما لا يعمل على الرابط المباشر (Pages)

تسجيل الدخول، اللوحات، حفظ البيانات، ومزامنة الكتالوج من الخادم (`/api/*`) — كلها تتطلب الخادم. الحاسبة على Pages تعمل بالكتالوج المحلي المضمّن (مع احتياط تلقائي عند غياب الخادم).
